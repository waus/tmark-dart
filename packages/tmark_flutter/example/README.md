# Tmark example

Flutter gallery demonstrating tmark text, lists, tables, maps, media, math,
code highlighting, and custom application renderers.

```sh
flutter pub get
flutter run
```

Documents are fetched by filename from <https://tmark.waus.app/examples/>.
The app requires internet access. Browser use requires that server to permit
cross-origin requests.

Run `flutter test` for document loader coverage. This app is not published to
pub.dev; its package dependencies use local paths in this repository.
